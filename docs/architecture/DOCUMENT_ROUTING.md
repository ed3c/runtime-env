# Document routing — runtime-env binding

This repository adopts the common route interface defined by the four-repository parent issue `ed3c/bettor-arena#35`.

```text
README / AGENTS
→ CONTEXT + ARCHITECTURE
→ docs/INDEX
→ nearest directory README
→ catalog/schema/module/profile/workload/policy/CLI/test
→ traceability/evidence
```

Assertions:

- root routes and relative links are explicit;
- every governed directory has a nearest README or named inheritance;
- current state and target design are separate;
- no README becomes a second catalog/schema/binding/receipt authority;
- no portable document carries actual secret values, sessions, or specific host checkout dependencies;
- the same four-repository role table is preserved;
- source proposals do not become runtime or provider PASS.

A generic home-directory convention may be documented as a host example; it is never a portable value or immutable subject. Consumer hooks remain independent of checkout layout.
